# Kickstart

## Why the weird name?
We associate "kickstart" with cold starting a scooter or a bike. Unlike electric starts, "kickstart" gives you more control, lower maintenance, and avoids drawing heavy current from the battery when it is cold and less efficient. 

That's what this is!

It's single repo that contains everything I need to get started on a new laptop - work or personal. 

## Components
* [Homebrew](https://brew.sh/)
* [Wezterm](https://wezterm.org/installation.html)
